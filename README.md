# ミチシル｜キャリア相談サービス LPデモ

**自主制作による、架空のキャリア相談サービスのデモサイトです。実在するサービスの申込窓口ではありません。**

イベントポスターの配色・タイポグラフィ・人物イラストをもとに、Webならではのレイアウトとインタラクションへ展開した制作実験です。第三者によるデザイン・UI/UX・CV導線のレビューを目的に公開しています。

- 公開先：Cloudflare Pages（接続・デプロイはまだ実施していません）
- [Cloudflare Pagesの推奨設定](CLOUDFLARE-PAGES.md)
- [公開用HTML](docs/index.html)

## レビューしていただきたいこと

- ファーストビューの印象、読みやすさ、ポスターとの世界観のつながり
- PC・スマートフォンの操作性と情報の読み進めやすさ
- モヤモヤの複数選択、モデルケースの比較、FAQの操作感
- 無料相談CTAからフォームまでの導線と安心感

## 実装

HTML・CSS・JavaScriptのみの静的サイトです。外部ライブラリやビルド依存パッケージは使用していません。

- PC・スマートフォン対応
- モヤモヤカードの複数選択
- 人物・相談テーマと連動するBefore / Afterスライダー
- キーボード操作・ARIAに対応したFAQアコーディオン
- 予約フォームの入力・確認・修正・完了画面
- マーキーの停止・再開と、動きを減らす設定への対応

## デモフォームについて

**実際の予約・外部送信・メール送信は行いません。入力内容をブラウザへ永続保存しません。架空の情報でお試しください。**

JavaScript無効時や初期化失敗時には入力・送信を無効に保ちます。モデルケース・気持ちの指標・サービス内容は制作上の仮設定であり、実際の体験談・測定結果・提供サービスではありません。

## ファイル構成・公開方法

```text
docs/
  index.html
  style.css
  fv-reference.css
  faq.css
  release.css
  script.js
  faq.js
  assets/          # 使用する人物イラストと支給SVG
  .nojekyll
```

Cloudflare PagesのGit連携で、Production branchを **`main`**、ビルドコマンドを **`exit 0`**、ビルド出力ディレクトリを **`docs`** に設定します。Root directoryはリポジトリルート、Framework presetはNoneです。完成済みの静的ファイルをそのまま配信し、素材はすべて相対パスで参照しています。バックアップ、制作途中の比較版、未使用の元画像、スクリーンショットは公開ファイルに含めていません。

ローカルでは `docs/index.html` をブラウザで開くか、`docs/` を静的HTTPサーバーで配信して確認できます。
